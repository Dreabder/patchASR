# Numerical-regression reference case

This directory contains the fixed reference case used for numerical
regression testing of `patchASR`.

The case corresponds to:

- evolutionary model: Brownian motion;
- tree configuration: balanced;
- shift magnitude: 16;
- replicate: `rep_001`.

Files:

- `tree.nwk`: phylogenetic tree used for the regression case;
- `node_traits.csv`: simulated trait data and shift metadata;
- `legacy_patch_4methods.csv`: frozen reference ancestral-state
  reconstruction output generated by the original research
  implementation for PIC, ML-BM, GLS-BM, and Rphylopars-BM;
- `SHA256SUMS`: checksums for the fixed reference files.

The legacy output is retained as a fixed numerical reference. Current
`patchASR` results are regenerated during regression validation and are
compared against this reference rather than stored as a second fixed
reference output.

Bayesian validation is performed separately through direct adapter
comparison and reproducibility checks because the Bayesian reconstruction
is stochastic.
